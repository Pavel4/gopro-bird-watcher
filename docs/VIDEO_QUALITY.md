# Анализ качества видео: GoPro через стекло

Анализ узких мест качества видео с GoPro в режиме USB-вебкамеры,
съёмка через два стекла на расстоянии ~1.5м до кормушки.

---

## Текущая конфигурация

- **Камера:** GoPro (webcam mode, USB-C)
- **Разрешение:** 1920x1080 @ 30fps
- **Запись:** FFmpeg → MPEG-TS, preset `fast`, CRF 16
- **Извлечение:** preset `slow`, CRF 17
- **Условия:** через два стекла, расстояние ~1.5м

---

## Узкие места качества (по степени влияния)

### 1. GoPro Webcam Mode — главный ограничитель (~60% потери)

GoPro в режиме вебкамеры через USB отдаёт **сжатый H.264 поток**
с битрейтом примерно **4-8 Мбит/с** на 1080p.

Для сравнения, при нативной записи на SD-карту GoPro Hero 11
пишет **45-60 Мбит/с** при том же 1080p — разница в **8-10 раз**.

Данные, которые приходят с камеры, УЖЕ потеряли большую часть
деталей ещё до того, как FFmpeg их получает. Дальнейшее
перекодирование (CRF 16, preset fast) не может вернуть то,
что было потеряно при USB-стриминге.

### 2. Широкий угол GoPro + расстояние 1.5м (~25% потери)

GoPro имеет сверхширокий объектив (~16mm эквивалент). На расстоянии
1.5м кормушка занимает примерно **5-10%** площади 1080p кадра.
Даже после кропа это **~200x200 пикселей** полезной информации —
очень мало для чёткого изображения птицы.

### 3. Два стекла (~15% потери)

Два слоя стекла дают:
- Потерю резкости (каждая поверхность рассеивает свет)
- Отражения (особенно при контровом свете)
- Цветовой сдвиг (зеленоватый оттенок)
- Конденсат между стёклами зимой

## Программные улучшения

### A. FFmpeg пост-обработка при извлечении видео

Добавить фильтры в цепочку обработки (после crop, перед scale):

```
crop → hqdn3d → unsharp → scale(lanczos)
```

Конкретно:
```
hqdn3d=1.5:1.5:6:6    — шумоподавление (убирает шум от стекла)
unsharp=5:5:0.8:5:5:0.3 — повышение резкости (компенсирует стекло)
scale=...:flags=lanczos  — качественный апскейлинг
```

**Ожидаемый эффект:** +15-20% субъективного улучшения.
Видео станет чище и четче, но новые детали не появятся.

Реализация: добавить `ENHANCE_VIDEO=true` в конфиг,
флаг `--enhance` в `run-native.sh`.

### B. Оптимизация параметров записи

Текущие настройки уже близки к оптимуму:
- CRF 16 + preset `fast` для источника — отлично
- CRF 17 + preset `slow` для извлечения — отлично
- Понижать CRF ниже 14 не имеет смысла — исходный поток
  уже сжат до 4-8 Мбит/с, больше деталей просто нет

## Физические улучшения

### C. Уменьшить расстояние (самый большой эффект)

- **Камеру вплотную к стеклу** — убирает ~50% отражений
- **Присоска на стекло** — GoPro Suction Cup Mount (~1500 руб)
- **Кормушку ближе к окну** — идеально 30-50 см

### D. Убрать одно стекло

- Приоткрыть форточку/окно — качество резко возрастёт
- Камера МЕЖДУ стёклами (если есть двойная рама)
- Лучший вариант: камера СНАРУЖИ в защитном кожухе

### E. Антибликовая плёнка / поляризационный фильтр

- **Поляризационный фильтр (CPL)** на объектив GoPro —
  убирает ~90% отражений от стекла
- Polar Pro CPL для GoPro (~2000 руб)
- Антибликовая плёнка на внутреннее стекло

### F. Освещение

- Погасить свет в комнате — убирает отражения
- Чёрная ткань/картон за камерой — аналогичный эффект

## Альтернативные подходы (максимум качества)

### G. GoPro нативная запись + OpenGoPro API

Не использовать webcam mode. Управлять камерой через
[OpenGoPro API](https://gopro.github.io/OpenGoPro/) по USB/Wi-Fi:
- Запускать/останавливать запись на SD-карту (4K/60fps, 60 Мбит/с)
- Скачивать файлы по USB/Wi-Fi
- При детекции движения: команда «начать запись» → «стоп» → скачать → отправить

**Плюсы:** качество в 10 раз лучше, нативный 4K.
**Минусы:** задержка ~5-10с на старт/стоп/передачу, износ SD.

### H. Специализированная камера для кормушки

Если нужен максимум качества:
- **Birdfy Feeder Camera** (~$170) — камера в кормушке, 1080p, AI 6000+ видов
- **Ring Stick Up Cam** — weatherproof, 1080p HDR, Wi-Fi
- IP-камера с **оптическим зумом** (3-5x) — кардинально лучше
